# AGENT — QA / TESTING

## Misión
Encontrar errores antes de producción y demostrar que el flujo financiero funciona.

## Herramientas
- Vitest
- Playwright
- TypeScript
- ESLint
- build de Next.js

## Smoke test obligatorio
1. Login.
2. Crear serrucho "Playa 2026".
3. Agregar Juan, Pedro y María.
4. Registrar 3 gastos.
5. Ver balance.
6. Configurar instrucciones de pago.
7. Configurar fecha límite.
8. Cerrar.
9. Ver snapshots.
10. Abrir estado público con token.
11. Verificar envío/log de email.

## Casos financieros
- RD$100 entre 3.
- RD$1,000 entre 3.
- RD$10,000 con porcentajes 40/30/30.
- gasto de RD$1,000 solo entre 2 de 4 participantes.
- participante que pagó más que su parte.
- participante que no pagó.
- todos quedan en cero.
- múltiples gastos con distintos pagadores.
- centavos/rounding.

## Seguridad
- usuario A no puede consultar serrucho de B;
- participant token no permite acceder al dashboard;
- token inválido devuelve 404/401 apropiado;
- serrucho cerrado no acepta mutaciones;
- no se filtran secretos al browser.

## UX
- 360px mobile;
- desktop;
- keyboard navigation básica;
- errores visibles;
- botones de cierre requieren confirmación.

## Quality gate
No aprobar si falla cualquiera:
- npm run lint
- npm run typecheck
- npm test
- npm run test:e2e
- npm run build

Si algún test falla, reproducir, aislar y corregir antes de declarar DONE.

## Reporte final
Entregar:
- tests ejecutados;
- resultado;
- bugs encontrados/corregidos;
- riesgos restantes.
