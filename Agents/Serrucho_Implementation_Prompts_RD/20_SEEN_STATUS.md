# 20 — Estado de participantes: visto / acceso

## Prompt para Antigravity

Implementa el concepto de presencia/acceso de participantes inspirado en Kittysplit.

### Objetivo

El creador debe poder saber cuáles participantes ya entraron al Serrucho.

### Estados

Como mínimo:
- invitado;
- accedió;
- identificado;
- cuenta vinculada.

### UX

Mostrar una marca discreta junto al participante.

No presentar esto como vigilancia.

### Privacidad

No registrar datos innecesarios.

El estado debe significar únicamente que el participante abrió/accedió al Serrucho.

### Criterios

- enviar invitación;
- participante abre enlace;
- estado cambia;
- creator puede verlo;
- no se expone IP, ubicación ni datos técnicos al grupo.
