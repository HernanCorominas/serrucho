# 31 — Localización dominicana profunda

## Prompt para Antigravity

Haz una pasada de localización de Serrucho para República Dominicana sin alterar el motor financiero.

### Moneda

- DOP como default.
- Mostrar RD$ de forma consistente.
- Mantener ISO DOP internamente.
- Soportar USD y otras monedas.

### Fechas

Usar formato comprensible para RD, manteniendo representación ISO en backend.

### Categorías

Priorizar:
- colmado;
- supermercado;
- delivery;
- gasolina;
- restaurante;
- alquiler;
- luz;
- agua;
- internet;
- teléfono;
- transporte;
- regalos;
- viajes.

### Lenguaje

Usar:
- "Serrucho";
- "gasto";
- "te deben";
- "debes";
- "saldar";
- "pagado";
- "compartir".

Evitar lenguaje excesivamente bancario.

### Compartir

Prioridad:
1. WhatsApp;
2. copiar enlace;
3. compartir sistema;
4. QR.

### Pagos

No asumir que Serrucho procesa dinero. Registrar y conciliar pagos es diferente a mover dinero.

### Criterios

Revisar todas las pantallas y eliminar referencias que parezcan importadas directamente de una app europea.
